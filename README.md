# Historia Propia — índice del proyecto
 
Bienvenido/a de vuelta. Este README es el mapa general: qué hay en cada carpeta y en qué orden conviene leer las cosas si retomas el proyecto después de un tiempo sin tocarlo.
 
---
 
## Si vuelves después de mucho tiempo y no recuerdas nada, lee en este orden:
 
1. `06_Estilo_y_Tono.md` — para recordar el tono y las líneas rojas de contenido antes de escribir nada.
2. `00_Contexto/Contexto_de_la_Academia.md` — el mundo, las tres divisiones, las reglas del reclutamiento.
3. `00_Contexto/Glosario.md` — si te topas con un término y no recuerdas qué significa.
4. `03_Personajes/Principales/` — ficha por ficha, empezando por los que tengan estado 🟢 o 🟡.
5. `05_Tramas/Cronologia_general.md` — para ubicarte en el tiempo de la historia.
